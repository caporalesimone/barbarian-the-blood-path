VICE parte sullo schermo dal vivo (velocità reale, audio): nello schermo grande si usa la tastiera del PC, e i pulsanti in alto Tastiera (tastiera C64 a video), Joy 1, Joy 2 (porta 2 = quella del gioco), Audio. Dal menu di VICE (barra in alto nella sua finestra: File → Smart attach / Attach disk image) si monta qualunque file del progetto (in /work). File tuoi: copiali in out/tmp/ (.d64 .g64 .prg .t64 .crt) e compaiono qui sopra; out/tmp/ si può cancellare a ogni pulizia. Dalla shell: toolchain/viewer.sh exec tools/vice/play.sh <file|versione|--bare> oppure toolchain/viewer.sh exec x64sc ... con le opzioni che vuoi.
